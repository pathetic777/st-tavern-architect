​3D Tavern Architect (圣酒馆建筑师)
​[English] | [中文说明](./README_zh.md)


​An interactive, real-time 3D scene and architecture generator extension for SillyTavern. Powered by a lightweight Dual-Agent pipeline and Three.js, it transforms narrative spatial context and room descriptions into browsable 3D environments without heavy local rendering overhead.
​✨ Features
​Dynamic 3D Generation: Automatically builds rooms, layouts, and furniture derived from chat context and spatial prompts.
​Interactive Roaming: Inspect spaces with free orbit camera controls or first-person perspective roaming.
​Ultra Lightweight: Built with pure WebGL and Three.js, requiring zero extra GPU VRAM for local inference.
​Bilingual Interface: Seamless switching between English and Chinese inside the control panel.
​📦 How to Install
​Method 1: In SillyTavern (Recommended)
​Open SillyTavern, click the Extensions (blocks icon) menu, and open Install Extension.
​Paste the repository URL:
https://github.com/pathetic777/st-tavern-architect
​Click Install, then refresh/reload your SillyTavern tab.
​Method 2: Manual Installation
​Clone this repository directly into your third-party extensions directory:
git clone https://github.com/pathetic777/st-tavern-architect.git public/scripts/extensions/third-party/st-tavern-architect
