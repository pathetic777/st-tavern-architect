# 🏛 酒馆建筑师 (Tavern Architect)

> **SillyTavern 通用 3D 场景与空间生成工作台**  
> 基于双 Agent 视觉认知与 Three.js 实时渲染的酒馆空间拓展插件。

---

## ✨ 核心特性

- 🧠 **双 Agent 协同流水线**：
  - **Agent 1 (认知与解构)**：支持视觉图纸直通，解析空间拓扑、比例与常识语义。
  - **Agent 2 (代码流式重组)**：将空间构想流式编译为标准化参数，驱动 3D 引擎。
- 🌐 **Three.js 实时三维视口**：
  - 支持复杂室内户型、建筑外立面、结构门窗与家具软装的高精度建模。
  - 原生支持实时光影渲染、轨道旋转、缩放与第一人称视线漫游。
- 🛡️ **CodeDefenseGuard 代码自愈引擎**：
  - 内置沙箱执行防御与代码语法自愈，杜绝异常崩溃。
- 📦 **零侵入无感集成**：
  - 基于独立容器隔离运行，不污染酒馆原生上下文，保障数据流纯净稳定。
